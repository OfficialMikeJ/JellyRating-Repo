Media Ratings

Assign a US or Canadian parental rating to movies, documentaries, series or seasons.

  1. Your media loads automatically — every movie, documentary and series from all libraries. Narrow it with the Library/Type/Search filters if you want.
  2. To rate one item: use that row's Set rating dropdown — it saves instantly.
  3. To rate many at once: tick the checkboxes (or Select All), choose a Rating in the bar below, press Save Ratings. "Remove Override" falls back to the metadata rating.
  4. Series cascade to every season and episode automatically. Click ▸ seasons to rate one season differently.

User Restrictions

Select users and assign a maximum permitted content level. Content above the level is hidden and blocked for every Jellyfin client — the user cannot bypass it by guessing an item id or playback URL. Administrators are never restricted.

  1. Tick one or more users.
  2. Choose the maximum allowed rating — anything above it is blocked; "Unrestricted" removes the limit.
  3. Press Save user policy. What unrated content does is decided by the setting on the Settings tab.

Rating Systems

The catalogue of rating levels the plugin offers in Media Ratings and User Restrictions. Raw metadata values are normalized before evaluation; US and Canadian levels compare through a fixed numeric score table — never by name — so cross-system limits work correctly.

SystemIdDisplayLevel (score/sub)

Add custom rating

Define your own level. Score ≈ minimum age (US-R = 17). Sub-score breaks ties inside a score (CA 18A = 18/1 sits just below 18+ = 18/2). Jellyfin value is the string written onto items — something Jellyfin understands (US:R, CA:18A, or a plain number like 19); if it can't be resolved the plugin substitutes a verified equivalent so enforcement never silently weakens. Aliases let metadata like "18-A" map to the level.
